# Numerical Computing & Array Operations with NumPy

This repository contains practical exercises, numerical routines, and array manipulation workflows using the **NumPy** library in Python.

## Overview & Mathematical Context

As an undergraduate mathematics student, I focus on NumPy as the computational backbone for numerical linear algebra, vector calculus, and data-driven scientific workflows. This repository demonstrates how core mathematical operations translate into efficient, vectorized code.

## Key Concepts & Operations Covered

- **Array Creation & Structural Manipulation:**
  - Multi-dimensional array structures (`ndarray`), shapes, and strides.
  - Matrix reshaping, flattening, stacking, and transpositions.
- **Vectorized Computations & Broadcasting:**
  - Fast element-wise mathematical operations avoiding explicit Python loops.
  - Broadcasting semantics across arrays with incompatible shapes.
- **Numerical Linear Algebra:**
  - Dot products, matrix multiplication (`@` operator and `np.dot`), and inner/outer products.
  - Determinants, matrix inverses, and eigenvalues/eigenvectors using `numpy.linalg`.
- **Indexing, Slicing & Boolean Masking:**
  - Multi-axis slicing, fancy indexing, and conditional filtering.
- **Mathematical & Statistical Functions:**
  - Reductions (`sum`, `mean`, `std`, `var`, `min`, `max`) across specific dimensions/axes.

## Tech Stack & Tools

- **Programming Language:** Python 3.x
- **Core Library:** NumPy
- **Environment:** Jupyter Notebooks, Google Colab
